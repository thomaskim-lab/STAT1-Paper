# STAT1-Paper

Analysis repository for the **STAT1 paper**, containing reproducible workflows for bulk RNA-seq, single-cell RNA-seq, single-cell ATAC-seq, flow cytometry, and SABER-FISH analyses.

This repository contains analysis scripts, metadata, curated gene sets, processed outputs, and session information supporting the study.

## Repository Structure

```text
.
├── Bulk_RNA-Seq/
├── scRNA-Seq/
├── scATAC-Seq/
├── metadata/
├── gene_sets/
├── results/
├── session_info/
└── README.md
```

### `Bulk_RNA-Seq/`

R scripts for bulk RNA-seq analysis of HMC3 cells and primary mouse microglia.

Analyses include:

* Plasmidsaurus DGE RNA-seq data processing
* HMC3 bulk RNA-seq analysis
* Primary microglia bulk RNA-seq analysis
* Differential gene-expression analysis
* STAT1/Stat1 siRNA perturbation analysis
* LPS-response analysis
* IFNγ rescue analysis
* Gene-set and pathway enrichment
* Expression visualization and summary statistics

### `scRNA-Seq/`

R scripts for analysis of **10x Genomics single-cell RNA-seq** datasets.

Analyses include:

* Data import
* Quality control
* Cell filtering
* Sample integration
* Dimensionality reduction
* Clustering
* Cell-type annotation
* Microglia subsetting
* Differential expression
* Pathway and gene-module scoring
* Focused analysis of STAT1-associated transcriptional programs

### `scATAC-Seq/`

R scripts for analysis of **10x Genomics single-cell ATAC-seq** datasets.

Analyses include:

* Data import and quality control
* Chromatin-accessibility analysis
* Dimensionality reduction and clustering
* Cell-type annotation
* Differential accessibility
* Promoter accessibility
* Distal regulatory-element accessibility
* Peak-to-gene analyses where applicable
* Transcription-factor motif enrichment and activity analysis
* Integration with transcriptional programs identified by scRNA-seq

### `metadata/`

Sample annotation tables used throughout the analysis workflows.

Metadata may include:

* Sample identifiers
* Experimental conditions
* Treatment groups
* Species
* Cell type
* Time point
* siRNA condition
* LPS treatment
* IFNγ treatment
* Sequencing batch or order information

### `gene_sets/`

Curated gene modules used for focused pathway and module-score analyses.

These may include:

* STAT1-associated gene programs
* Interferon-response modules
* Inflammatory-response modules
* Microglial activation programs
* Experiment-specific transcriptional signatures

### `results/`

Processed outputs generated by the analysis workflows.

Examples include:

* Differential-expression tables
* Differential-accessibility tables
* Gene-set enrichment results
* Pathway-analysis outputs
* Module-score summaries
* Processed statistical results used for downstream visualization

### `session_info/`

R session-information files corresponding to major analyses in the repository.

These files document:

* R version
* Package versions
* Loaded libraries
* Analysis environment information

They are provided to support computational reproducibility.

## Bulk RNA-seq Experimental Designs

### HMC3 LPS Time Course

HMC3 human microglial cells were analyzed across an LPS stimulation time course to characterize inflammatory transcriptional responses and STAT1-associated gene-expression dynamics.

### STAT1 siRNA Perturbation

Multiple bulk RNA-seq experiments examined the effect of **STAT1 knockdown** using independent siRNAs.

Experiments include:

* STAT1 siRNA #1
* STAT1 siRNA #3
* 24-hour knockdown conditions
* 48-hour knockdown conditions
* Conditions with and without LPS stimulation

Using multiple siRNAs enables evaluation of transcriptional changes consistently associated with STAT1 depletion.

### Primary Mouse Microglia

Primary mouse microglia were analyzed following **Stat1 knockdown**.

Conditions include:

* Untreated cells
* Lipofectamine-only controls
* Stat1 siRNA #1
* Stat1 siRNA #3
* 48–72-hour perturbation conditions

### IFNγ Rescue

An additional primary-microglia experiment evaluated Stat1 perturbation in the presence or absence of **IFNγ rescue**.

This experiment was designed to assess the relationship between Stat1-dependent transcriptional regulation and interferon signaling.

## Single-Cell ATAC-seq Analysis

The scATAC-seq workflows examine changes in chromatin accessibility associated with STAT1-related cellular states.

Analyses include:

* Cell-level quality control
* Peak and fragment processing
* Latent-space construction
* Clustering
* Differential chromatin accessibility
* Promoter accessibility
* Distal-element accessibility
* Transcription-factor motif analysis

Where appropriate, accessibility changes are compared with transcriptional changes identified by RNA-seq.

This enables investigation of the regulatory architecture associated with STAT1-dependent gene-expression programs.

## Reproducibility

All primary analysis scripts were written and executed in **R**.

Package versions and R session information are recorded in:

```text
session_info/
```

Where available, the corresponding package environment is additionally captured using:

```text
renv.lock
```

If an `renv.lock` file is provided, the R environment can typically be restored using:

```r
install.packages("renv")
renv::restore()
```

Users should refer to the session-information file associated with each analysis for exact package versions.

Because single-cell RNA-seq and ATAC-seq analyses can require substantial memory and compute resources, hardware requirements may vary depending on the dataset and analysis step being reproduced.
