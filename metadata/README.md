# Metadata

This folder contains sample-level metadata used for the STAT1 paper analyses.

## Files

- `bulk_rnaseq_dataset_summary.csv`: overview of bulk RNA-seq and DGE RNA-seq datasets, including order ID, cell type, species, sample number, experiment type, and analysis status.
- `bulk_rnaseq_sample_map.csv`: master sample map for all bulk RNA-seq datasets used in the analysis.
- `hmc3_lps_barcode_metadata.csv`: sample/barcode metadata for the HMC3 LPS bulk RNA-seq dataset.
- `plasmidsaurus/`: Plasmidsaurus order-specific sample maps.

## Plasmidsaurus order maps

- `5SZCYD.csv`: HMC3 STAT1 siRNA 24 h pilot.
- `BN4GZZ.csv`: HMC3 STAT1 siRNA 24 h experiment.
- `R4NCSL.csv`: HMC3 STAT1 siRNA with or without LPS at 48 h.
- `3BNGF5p.csv`: primary mouse microglia Stat1 siRNA experiment.

## Notes

Raw sequencing files are not stored in this repository. Sensitive information, including login credentials, invoices, billing details, animal order forms, and internal submission documents, should not be committed.
